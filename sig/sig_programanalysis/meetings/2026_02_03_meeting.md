**议题2、基于细粒度性能自动化剖析的鸿蒙应用负载优化研究进展**  
汇报人：尹韶璞  
会议结论：  
1、汇报自动化测试工具定位与整体架构，包含UI状态管理、探索策略、UI 数据采集和报告生成模块；  
2、实现智能UI状态管理，从Inspector递归提取可点击元素，并基于目标应用包名进行过滤；采用元素树结构MD5哈希进行状态去重，避免重复访问相同页面；  
3、打通核心测试流程，支持深度优先、广度优先和随机探索策略，并在UI操作过程中同步采集CPU、内存、trace等性能数据，生成可视化HTML报告；  
4、讨论后续优化方向，包括探索策略改进、性能数据与UI状态的无损同步采集、测试报告可读性提升，以及单应用测试耗时、HapRay代码仓更新和集成代码提交审查等问题。

**议题4、面向鸿蒙系统的字节码切片与大模型语言理解双驱动的代码分析智能体进展**  
汇报人：李浩远  
会议结论：介绍模块初始化分析及切片优化：  
- 一是明确初始化逻辑，借鉴单例模式在 `init()` 中加 Guard if 语句，将 `config.ts` 等模块转为带静态 `isInitialized` 判断的类初始化方法；  
- 二是涉及切片图构建，梳理了 Main 调用 FeatureA/B init 的调用关系及配置修改、初始化判断等关键节点；  
- 三是提出剪枝策略提效，包括构建 Module Dependency Graph 做可达性分析，以及基于执行序列号的规则——若模块写操作执行序列号晚于 Sink 所在模块，则可剪枝（如 Logger 模块 Index 3 大于 Feature 的 Index 2，其修改不影响 Sink 时可剪枝）。
